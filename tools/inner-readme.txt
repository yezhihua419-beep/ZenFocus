How to run
1. Keep the whole folder. Do not copy only ChanJing.App.exe.
2. Right-click ChanJing.App.exe → Run as administrator (needed to write the hosts file).
3. Windows may warn about an unsigned app — choose Run anyway.

Limits (not bugs)
- Without administrator: YouTube/TikTok tabs stay open; you only get a distraction bubble.
- Store / PWA windows minimize only when the title matches the block list.
- There is no payment page. Gray-locked items open an upgrade note.

Please try

- Left-click a second scene (still applies); right-click it (upgrade note)
- Add a 4th custom domain
- Stats → Export
- Block page → Diagnose → Import / Export
- Switch English / 中文
- Tray or Ctrl+Alt+F to end = early stop (streak should not increase)
- Display scale 125% / 150%: home scene buttons and the bottom bar

Data: %LOCALAPPDATA%\ChanJing\
