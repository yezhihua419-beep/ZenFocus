# 禅净 ChanJing

> 先管住手，再看清时间 —— Windows 桌面「时间主人」教练

禅净是一款 Windows 桌面专注 / 防沉迷工具。系统级屏蔽 + 本地统计 + 禅意体验，
帮你管住电脑前的网页分心，看见自己的时间去向。

## 产品定位

- **一句话**：先管住手（系统级屏蔽），再看清时间（本地统计洞察）
- **目标用户**：在电脑前学习 / 工作、分心于浏览器的人（远程办公者、程序员、写作者、电脑备考者）
- **差异化**：系统级屏蔽体系 + 国内网站名单 + 局域网移动联动 + 零截图隐私叙事
- **竞品锚点**：Cold Turkey（海外，屏蔽强）、TimeLens（国内，纯统计无屏蔽）、Forest（移动端，订阅翻车反面教材）

## 核心功能（V1 / MVP）

| 模块 | 功能 |
|---|---|
| 屏蔽体系 | 国内分类名单（B站/抖音/小红书/微博/淘宝/知乎热榜/斗鱼）+ 自定义域名黑名单 + 每日限额 + 紧急出口（临时放行）+ 摩擦式退出（5-10 秒冷静期） |
| 专注引擎 | 番茄钟（默认正计时）+ 今日一愿 + 专注后即时反馈 + 破功仪式（"发生了什么？"） |
| 统计 | 按应用/网站时长 + 日/周视图 + 7 日趋势（SQLite 本地存储，零上传） |
| 系统集成 | 托盘 + 开机自启 + 管理员权限 + 前台窗口采集（仅进程名+标题哈希） |
| 移动联动 | 局域网 Web 伴侣页（手机浏览器看统计/远程控制，零云端） |

## 抗焦虑设计原则

- 藏起剩余时间（正计时显示已用时），不制造倒计时焦虑
- 给足出口：紧急出口永远可见、冷静期后可走、限额随时可调
- 教练话术：进步框架（"比昨天多 5 分钟"），不审判（"你又浪费了…"）
- 把"禁止"变"留白"：开始专注 3 秒呼吸引导，破功用赭石色提问而非刺眼红

## 技术栈

- C# / .NET 8 LTS
- WinUI 3（Microsoft.WindowsAppSDK）
- SQLite（本地存储）
- 屏蔽实现：hosts 劫持（标记段管理，不碰其他条目）+ SYSTEM 计划任务守护

## 开发命令

```powershell
# 构建
dotnet build ChanJing.sln

# 运行（需 Windows App SDK 运行时）
dotnet run --project src/ChanJing.App

# 测试
dotnet test ChanJing.sln
```

## 隐私承诺

- 数据全本地（SQLite），零上传、零截图
- 前台窗口仅采集进程名 + 标题哈希，不落明文标题
- 无账号、无云端、无遥测
