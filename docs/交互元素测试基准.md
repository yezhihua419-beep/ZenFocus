## 一、首页（MainPage）

### 1. 场景按钮（工作/写作/学习/会议）— 左键点击

| 项目 | 内容 |
|---|---|
| 元素 | 4个按钮：SceneWork(tag=work)、SceneWrite(tag=write)、SceneStudy(tag=study)、SceneMeeting(tag=meeting) |
| 直接结果 | ① 按钮高亮（苔青背景+白字）；② 愿望框填充场景预设愿望；③ 时长设置为场景预设时长；④ 屏蔽分类切换为场景预设分类；⑤ 场景摘要(SceneConfigHint)更新为"场景名 · X分钟 · 屏蔽N类（分类列表） · 右键可自定义" |
| 间接结果 | ① AppServices.CurrentSceneTag更新；② 若旧场景已自定义，先保存当前配置到旧场景（防止切换后修改丢失）；③ AppServices.CurrentWish/CurrentMinutes更新 |
| 状态依赖 | 专注中点击：应无效或提示（需确认当前行为） |
| 已知问题 | 无 |
